# Barpi Brand Book — пастки, архів 2026 Q2–Q3 (одноразові, старші за 90 днів)

Переносяться дослівно з `docs/traps.md` при ротації. Читати лише коли питання веде в минуле.


### Гейтована сторінка без `bb.js` не гейтована
**Симптом:** дашборд відкривається без CF Access-топнаву і без перевірки.
**Причина:** `/dashboard/events/` не підключав `bb.js`, який ставить auth-gate і topnav.
**Дій:** кожна нова сторінка під `/dashboard/` підключає `assets/bb.js`; перевірка — відкрити в приватному вікні.
**Seen:** 02.06.2026 (`35b7cba`)

### Зовнішні файли й іконки з чужого домену дають 404
**Симптом:** 15 сторінок лінкують favicon, якого немає; 22 сторінки посилаються на `og-image.png`, якого немає.
**Причина:** іконки тягнулися з `barpi.com.ua`, а og-картинка існувала тільки як `og.svg`. Плюс 25+ посилань на файли в Google Drive у `/downloads/` і `/fonts/`.
**Дій:** усе, що потрібне сайту, лежить у репо або в R2. `og-image.png` рендериться воркфлоу `og-image.yml` з `og.svg` — правити треба SVG, а не PNG.
**Seen:** 07.07.2026 (`c112637`, `01d41d3`)

### Документація описує контур, якого вже немає
**Симптом:** інструкція веде в Supabase-проєкт `barpi-hq`, дашборд віддає HTTP 000, у списку проєктів його немає.
**Причина:** дані переїхали на Cloudflare D1 (v3.4–v4.1, 02.06.2026), а `CLAUDE.md`, `DEPLOY_NOTES.md` і `supabase/functions/telegram-bot/README.md` лишилися з Supabase-контуром. Такий самий дрейф раніше був у `README.md`.
**Дій:** не вір документу без звірки з деревом файлів і живим сервісом. Data-контур = D1 + `barpi-api`. Supabase-згадки — кандидати на прибирання (P2-9), не на виконання.
**Seen:** 07.07.2026 (P2-9)

### Секрет у HTML дашборда потрапляє в git-історію назавжди
**Симптом:** gitleaks мовчить (скан лише робочого дерева), а 64-символьний ключ лежить у комітах.
**Причина:** `SYNC_API_KEY` був захардкоджений у `dashboard/sales-performance/index.html`, щоб кнопка «синхронізувати зараз» працювала з браузера. Видалення файлу історію не чистить.
**Дій:** ніякого ключа у фронтенді — кнопка показує тост «auto cron щогодини». Знайшов ключ у публічному файлі → спершу ротуй (`SECURITY.md` → Leak response), потім прибирай. `ci.yml` сканує з `fetch-depth: 1`, тобто історію не бачить.
**Seen:** 07.06.2026 (C2, коміт `7c226cca`)

### `${{ }}` усередині inline flow-map ламає парсер GitHub Actions
**Симптом:** воркфлоу падає ще до першого кроку — «startup failure», логів немає.
**Причина:** конструкція `with: { key: ${{ secrets.X }} }` у однорядковому вигляді — невалідний YAML для GitHub.
**Дій:** писати `with:` блоковим стилем, кожен ключ окремим рядком. Після правки воркфлоу — перевір `gh run list --limit 3`, «зелений пуш» без ранів означає, що воркфлоу не стартував.
**Seen:** 07.07.2026 (`492f62c`)

### Масове редагування HTML стискає контент, який ніхто не просив стискати
**Симптом:** сторінка після «косметичної» правки коротша на третину; текст переказано своїми словами.
**Причина:** агент правив десяток сторінок одним пакетом і по дорозі «оптимізував» розділи. Довелося робити сім комітів `Restore <page>/index.html verbatim`.
**Дій:** наскрізні правки — по одному файлу за раз, і `git diff --stat` перед комітом: рядків не має ставати менше, якщо задача не «скоротити». Розділів 25, кожен — окрема тека з `index.html`.
**Seen:** 28.05.2026 (серія `fe449c8`…`c2c691a`)
