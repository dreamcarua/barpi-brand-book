💻 CSS приклад використанняCSS usage example

/* Підключення шрифту Qanelas через @font-faceLoading Qanelas via @font-face */
@font-face {
  font-family: 'Qanelas';
  src: url('/assets/fonts/qanelas/Qanelas-Regular.woff') format('woff');
  font-weight: 400;
  font-style: normal;
}
@font-face {
  font-family: 'Qanelas';
  src: url('/assets/fonts/qanelas/Qanelas-Bold.woff') format('woff');
  font-weight: 700;
}

/* ВикористанняUsage */
body { font-family: 'Qanelas', 'Rubik', sans-serif; }
h1, h2 { font-weight: 700; }
