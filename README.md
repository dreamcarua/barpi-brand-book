Інтерактивний онлайн-документ бренду Barpi — український бренд натуральних смаколиків для собак і котів за запатентованою технологією SNECO.

> Турбота для справжніх друзів. Один інгредієнт. Без зайвого.

## Структура
- `index.html` — головний документ (18 розділів)
- `documents/` — PDF: ТМ, ТУ, патент, сертифікат, лаб-висновок
- `dashboard/` — SMM, Sales, Inventory, Partners, Events
- `logo/`, `fonts/` — асети
- `packaging/`, `equipment-photos/`, `event-photos/` — фото
- `retail/`, `strategy/`, `hr/`, `pricing/` — внутрішнє
- `barpi-auth/` — Cloudflare Worker (OTP-gate)
- `CLAUDE.md` — пам'ять для AI · `BACKLOG.md` — план · `CHANGELOG.md` — версії
