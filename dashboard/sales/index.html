Інтеграція з МойСклад

Архітектура (форк зі snEco):

  1. GitHub Action sales-sync.yml запускається щодня о 06:00 UTC
  2. Скрипт moysklad_sync.py тягне demand, customerorder, invoiceout з API
  3. Зберігає у Cloudflare D1 barpi-bible (таблиці sales_*)
  4. Цей HTML підвантажує дані через fetch('/api/dashboard/sales/data') з Worker barpi-auth
  5. OTP-gate перевіряє JWT перед видачею

Потрібно (від тебе у Q3 2026): MoySklad API token → GitHub Secret MOYSKLAD_TOKEN.
