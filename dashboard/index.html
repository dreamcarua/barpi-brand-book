🎪 Events Dashboard PLANNED

Фестивалі, дегустації, ROI. 12+ подій у 2026, бюджет, зразки, UGC.

Block: events-dashboard · Доступ: Альона + Мар'яна + Вадим
Стек: standalone HTML (GitHub Pages) + Cloudflare Worker barpi-auth (OTP email + JWT) + Cloudflare D1 barpi-bible (дані) + Cloudflare KV barpi-bible-acl (whitelist) + GitHub Actions cron (sync МойСклад → D1).

Доступ: кожен дашборд за email-кодом (10 хв на код, 24 год сесія). Whitelist редагується через admin endpoint Worker.
