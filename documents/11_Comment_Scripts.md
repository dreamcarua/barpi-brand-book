BARPI SMM 11 — Comment Scripts
===============================

Скрипти відповідей на коментарі під постами, Reels, Stories.

## 1. Принципи

— Відповідаємо на всі коментарі, навіть короткі ("дякую", "👍").
— Реакції лайком з акаунта Barpi — обов'язково для кожного коментаря.
— Перша відповідь — протягом 4 годин в робочий час.
— Дружньо, коротко, по суті.
— Не вступати в публічні суперечки — переводити у Direct.

## 2. Позитивний коментар ("Супер продукт!")

```
Дякуємо вам 💙 Раді, що ваш друг обрав Barpi!
```

```
Будемо дуже раді, якщо поділитеся фото у Stories і позначите нас @barpi.ua 🐾
```

## 3. Питання про склад

```
У [назва SKU] — один інгредієнт ([назва]) дбайливо висушений за технологією SNECO 🐾 Без зайвого.
```

## 4. Питання "Де купити?"

```
Офіційний сайт: barpi.com.ua
Партнери: MasterZoo, E-ZOO, Pethouse, GooDwine, GarapeT та інші → список у Highlights "Де купити".
Доставляємо по всій Україні 📦
```

## 5. Питання про ціну

```
Ціни на [SKU] від [сума] грн. Детальніше — на barpi.com.ua. Якщо потрібна рекомендація, що обрати — напишіть нам у Direct 💙
```

## 6. Скептичний коментар ("А чому так дорого?")

```
Розуміємо ваше запитання 💙

Ціна відображає: один інгредієнт з контрольованої сировини, дбайливе вакуумне сушіння SNECO, лабораторний контроль готової продукції. До 95% поживних речовин залишається у кожному шматочку.

Рекомендуємо спробувати маленький формат для початку — відчуєте різницю!
```

## 7. Скарга у публічному коментарі

```
Нам дуже неприємно 💙 Написали вам у Direct, розберемося индивідуально і зробимо все можливе.
```

## 8. Тролінг / хейт

**Не видаляємо** коментар якщо він просто негативний, а відповідаємо спокійно:

```
Дякуємо за думку. Ми раді, коли люди діляться різними думками — це допомагає нам ставати кращими.
```

**Видаляємо та блокуємо** лише ї:
— Образи та лайка.
— Спам / рекламу інших брендів.
— Расистські/дискримінаційні висловлювання.
— Прямі заклики до бойкоту.

## 9. Реклама конкурента у коментарях

Не реагуємо публічно (не даємо додаткової уваги). Приховуємо коментар. Якщо це бот — репортимо.

## 10. Позитивні коментарі під UGC

```
Дякуємо, що поділилися! Свавжній друг [ім'я тварини] — красень 💙🐾
```

## 11. Частовживані реакції

— Якщо комент про тварину — "красень/красуня!", "справжній друг!".
— Якщо комент про смаколик — деталі + запрошення в Direct.
— Якщо жарт — відповідаємо жартом (без сарказму).
— Якщо вдячність — дякуємо у відповідь.

## 12. Не пишемо

— "Купуйте вже!"
— "Обирайте нас замість [конкурент]"
— Довгі рекламні тексти у коментарях.
— Медичні обіцянки.
— Сарказм або пасивна агресія.
