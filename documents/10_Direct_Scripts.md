==============================

Скрипти відповідей у Direct/DM. Як Barpi говорить з клієнтами один на один.

## 1. Принципи

— Перша відповідь — в течів години в робочий час (9:00-21:00).
— Поза робочим часом — auto-reply з обіцянкою відповісти.
— Дружній тон, без сухої формальності.
— Питати високоякісні питання, щоб підбрати продукт.
— Завжди дякувати за звернення.

## 2. Авто-вітання (в Instagram Auto-Reply)

```
Вітаємо у Barpi! 🐾

Ми вже бачимо ваше повідомлення. Відповідаємо протягом робочого дня (9:00-21:00, ЧК-Нд).

Поки очікуєте:
→ Каталог: barpi.com.ua
→ Де купити: посилання у профілі
```

## 3. Перший контакт (клієнт питає "Що обрати?")

```
Вітаємо 💙
З радістю підкажемо.

Напишіть, будь ласка:
— хто у вас — собака чи котик;
— вік;
— вага;
— чи є чутливість до якихось продуктів.

Підберемо Barpi, з якого буде найкраще почати 🐾
```

## 4. Питання про склад

```
Склад Barpi — як можливо простий.

Один інгредієнт (печінка / легені / рубець / серце тощо — залежно від SKU) дбайливо висушений за технологією SNECO. Без зайвого.

Готова продукція проходить лабораторні дослідження.
```

## 5. Питання про алергію

```
Дякуємо, що уважні до вашого друга 💙

У Barpi один інгредієнт — це допомагає краще розуміти, що ви даєте. Проте ми не можемо гарантувати відсутність реакції у конкретної тварини.

Рекомендуємо:
1. Порадитися зі своїм ветлікарем.
2. Почати з маленької порції.
3. Спостерігати протягом кількох днів.

Якщо потрібна конкретна порада — опишіть ситуацію детальніше.
```

## 6. Питання про технологію SNECO

```
SNECO — це запатентована українська технологія вакуумного сушіння. Ми дбайливо прибираємо вологу, залишаючи смак, аромат і хрумкість.

Технологія належить українським розробникам і захищена патентом на корисну модель UA № 160558.
```

## 7. Питання про котів

```
Так, у нас є котяча лінійка 🐱

Коти обожнюють [назви SKU для котів]. Маленький розмір шматочка + природний аромат працюють дуже добре.

Посилання на котячий розділ: barpi.com.ua/cat
```

## 8. Питання про доставку

```
Доставляємо по всій Україні:
— Нова Пошта (відділення / адресна)
— Укрпошта
— Justin

Строки: 1-3 робочі дні. Безплатно від [сума] грн.

Замовлення: barpi.com.ua
```

## 9. Скарга на товар (бита упаковка)

```
Дякуємо, що написали. Нам дуже прикро за це 💙

Надішліть, будь ласка:
— фото упаковки;
— номер замовлення або ЧПТТН;
— дату отримання.

Одразу перевіримо варіанти заміни або повернення.
```

## 10. Питання про опт

```
Дякуємо за зацікавленість! 💙

Ми раді можливостям партнерства. Напишіть, будь ласка, наm@barpi.com.ua або в цьому Direct:
— назва магазину/мережі;
— місто/регіон;
— орієнтовна кількість товару;
— контактна особа.

Перенаправимо вас до комерційного відділу.
```

## 11. Негативний відгук

```
Нам дуже неприємно чути це 💙

Щоб розібратися, розповіджте, будь ласка:
— хто у вас — собака/кіт;
— який SKU;
— що саме сталося.

Серйозно ставимося до кожної ситуації і зробимо все можливе, щоб навести лад.
```

## 12. Чого НЕ писати

— Медичні рекомендації (замість — "порадьтеся з ветлікарем").
— "Лікує / виліковує / усуває захворювання".
— "100% безпечно для всіх тварин".
— Обіцянки про конкретний результат (схудне/вилікує).
— Негативні згадки про конкурентів.
— Дописувати клієнта без його звернення — нав'язливий спам.
