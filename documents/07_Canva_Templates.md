BARPI SMM DOCUMENT 07 — Canva Templates
========================================

Система багаторазових шаблонів для Instagram, Stories, Reels, UGC, партнерів і продуктових постів.

**Версія:** 1.0

## 1. Навіщо потрібні шаблони

Стабільний вигляд Barpi навіть якщо змінюється SMM, дизайнер або підрядник. Швидко створювати пости, зберігати єдиний стиль, не вигадувати дизайн щоразу з нуля, використовувати правильні кольори і шрифт.

## 2. Головний принцип

**Шаблон = система, не приклад.** SMM змінює тільки: фото, назву продукту, 1-2 фрази, SKU-акцент, CTA, назву партнера, дату, посилання. Не змінює: логіку композиції, шрифт, стиль логотипу, пропорції, базові кольори.

## 3. Базова візуальна система

**Основні кольори:**

| Роль | Колір | HEX |
|---|---|---|
| Фон | Білий | `#FAFAFA` |
| Текст | Чорний | `#1A1A1A` |
| Брендовий акцент | Синій | `#2F6FED` |

**SKU-кольори (Product Accent Palette):** `#F7931D`, `#1E75BC`, `#00A79E`, `#D91A5C`, `#ED1D23`, `#39B44A`, `#00ADEE`, `#ED008C`, `#F15928`, `#91268F`.

**Правило:** в одному макеті — тільки один SKU-колір. Для маленької плашки, лінії, підкреслення, іконки, крапки, бейджа, номера слайду. Не для логотипу/фону/всього тексту/великих заливок.

## 4. Шрифт

**Rubik** (Google Fonts) — основний шрифт для всіх Canva-шаблонів Barpi.

| Рівень | Накреслення | Використання |
|---|---|---|
| H1 | Bold / ExtraBold | головні заголовки |
| H2 | SemiBold | підзаголовки |
| Body | Regular | короткі пояснення |
| Caption | Medium / Regular | дрібні підписи |
| CTA | SemiBold | кнопки, посилання, заклики |

Один макет = одна головна фраза. Не використовувати декоративні/рукописні шрифти.

## 5. Правила логотипу

Не перефарбовуємо під SKU; синій акцент не змінюємо; не розтягуємо/обрізаємо; не ставимо поверх шумного фото без підкладки; не головний елемент макета.

**Найкраще розташування:** нижній лівий/правий кут, верхній лівий для титульних слайдів, фінальний слайд каруселі. Якщо упаковка добре видна — логотип можна не дублювати.

## 7. Template 01 — Educational Carousel

5-7 слайдів, світлий фон, багато повітря, 1 думка на 1 слайд.

**Структура:** Слайд 1 хук → Слайд 2 пояснення → Слайд 3 технологія → Слайд 4 доказ → Слайд 5 фінал.

```
С1: Один інгредієнт. І все зрозуміло.
С2: Без складних складів. Без зайвих компонентів.
С3: Прибрали воду — залишили смак.
С4: Готова продукція проходить лабораторні дослідження.
С5: Barpi — турбота для справжніх друзів.
```

## 8. Template 02 — Product Post

Конкретний SKU. Один продукт, одне головне повідомлення, упаковка + смаколик. Упаковка справа/знизу, продукт крупним планом, багато повітря.

```
Печінка яловича

Один інгредієнт.
Без зайвого.
Дбайливо висушено.
```

## 9. Template 03 — Product Macro

Головний герой — фактура смаколика. Велике фото продукту, мінімум тексту. Приклади: "Хрумко. Ароматно. По-справжньому.", "Смак, який вони впізнають.", "Фактура, яку не треба прикрашати."

## 10. Template 04 — SNECO Technology

Теми: прибрали воду — залишили смак; вакуумне сушіння; до 95% поживних речовин; довший строк без консервантів; лабораторний контроль; SNECO простими словами. Без ракет, планет, sci-fi графіки.

```
Прибрали воду.
Залишили смак.

SNECO дбайливо видаляє зайву вологу
і допомагає зберегти смак, аромат і хрумкість.
```

## 11. Template 05 — UGC / Ambassador Post

Живі фото від клієнтів. Фото займає 70-90% макета, мінімум графіки, маленький логотип. Приклади: "Маленький ритуал турботи.", "Він почув пачку першим.", "Смак зайшов. Дуже."

UGC не має виглядати як рекламний банер. Його сила — у живому моменті.

## 12. Template 06 — Review Post

Відгуки клієнтів, партнерів, амбасадорів. Формат цитати:

```
"Він почув пачку
ще до того, як ми її відкрили."

@username
```

## 13. Template 07 — New Partner Story

```
Barpi вже ближче

Тепер шукайте нас у:
[назва партнера]

[місто / адреса]
```

Світлий фон, синя іконка локації, фото партнера/полиці, упаковка Barpi, логотип внизу.

## 14. Template 08 — Poll Story

```
Який смак ваш друг
обрав би першим?
```

Світлий фон, велике питання, фото продукту/тварини, місце для Instagram poll sticker.

## 15. Template 09 — Quiz Story

```
Правда чи ні?
Barpi містить один інгредієнт.
```

Білий фон, коротке питання, фото продукту, синій акцент, місце для quiz sticker.

## 16. Template 10 — Reels Cover

Єдині обкладинки Reels у форматі 9:16. Заголовки: "Один інгредієнт", "Без зайвого", "Він почув пачку", "Прибрали воду", "Barpi після команди", "Що обрати?", "Новий партнер". Живий кадр, великий Rubik, маленький логотип.

## 17. Template 11 — Set / Bundle Post

```
Почніть із сету

Щоб знайти улюблений смак
вашого друга.
```

Кілька упаковок, коробка/набір, продукт поруч, білий фон, синій CTA.

## 18. Template 12 — New Product Launch

```
Новий смак
[Назва продукту]

Один інгредієнт.
Без зайвого.
```

## 19. Що можна / не можна змінювати

**Можна:** фото, назву продукту, короткий текст, SKU-акцент, CTA, партнера, кількість слайдів у каруселі.
**Не можна:** шрифт Rubik, логотип, синій акцент, базову палітру, загальні відступи, стиль іконок, логіку композиції.

## 20. Чек-лист перед публікацією

Чи виглядає як Barpi; чи є повітря; чи не забагато тексту; чи правильно логотип; чи SKU-колір не домінує; чи немає 3-4 кольорів одночасно; чи реальне фото; чи немає AI-тварин у реальному контенті; чи CTA не агресивний; чи звучить дружньо.

```

Barpi_Carousel_OneIngredient_2026
Barpi_Story_NewPartner_Pethouse_2026
```

## 23. Архів

Не видаляти старі шаблони — переносити в `Archive`. Бачити історію стилю, не втрачати вдалі рішення, мати резерв.

## 24. Головне правило

Canva-шаблони мають допомагати Barpi виглядати стабільно, але не мертво. Система тримає бренд. Живі фото дають емоцію. Текст звучить як друг, який дбає.

**Barpi — турбота для справжніх друзів.**
