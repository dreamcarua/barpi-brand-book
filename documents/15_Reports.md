BARPI SMM 15 — Reports
=======================

Система регулярних звітів SMM-команди.

## 1. Щотижневий звіт

**Структура:**
1. KPI поточного тижня vs попереднього (охоплення, взаємодія, підписники, переходи на сайт).
2. Top-3 пости (рейтинг по reach/saves/shares).
3. Bottom-3 пости (що не спрацювало).
4. UGC: кількість репостів, найкращий UGC.
5. Директи: кількість, час відповіді, топ-питання.
6. План на наступний тиждень.
7. Блокери / виклики.

**Коли:** ПН ранком.
**Кому:** внутрішня команда + керівник.
**Формат:** 1 сторінка, числа + короткий коментар.

## 2. Щомісячний звіт

**Ключові метрики:**

| Метрика | Очікувана динаміка |
|---|---|
| Підписники IG | +5-10% / місяць |
| Охоплення | +10-20% |
| Engagement rate | 3-5% |
| Stories views | 30-40% від підписників |
| Reels views | 5× від постів |
| Profile → site | 5-8% |

**Розділи:**
1. Executive summary (1 речення).
2. KPI місяця vs план.
3. Розбивка по платформах: IG, TT, FB, Threads.
4. Найкращі рубрики / вважання.
5. UGC / амбасадори.
6. Партнери / колаби.
7. Бюджет (реклама, амбасадори, виробництво).
8. ROI по конкретним активностям.
9. Приріст sales з SMM каналів.
10. План на наступний місяць.

**Коли:** перший тиждень нового місяця.
**Кому:** засновники + комерційний відділ.

## 3. Квартальний звіт

**Розділи:**
1. Стратегічний огляд (чи досягли OKR).
2. Найважливіші висновки (3-5 булетів).
3. Порівняння Q vs Q.
4. Конкурентна розвідка.
5. Портрет авдиторії (є зміни?).
6. Новий плейбук (що змінити у наступному кварталі).
7. Бюджет на наступний квартал.

**Коли:** перший тиждень нового кварталу.
**Формат:** PDF + презентація.

## 4. Кампанійний звіт (після запуску)

Обов'язковий після кожної великої кампанії:
1. Ціль кампанії.
2. Бюджет (план vs факт).
3. KPI (план vs факт).
4. Деталі за каналами.
5. Що спрацювало / не спрацювало.
6. Рекомендації для наступної.

## 5. Дашборди (Live)

**Barpi HQ Dashboard:** brand.barpi.ua/dashboard/hq — оперативна робота SMM команди.
**Sales:** brand.barpi.ua/dashboard/sales — продажі по SKU / каналах.
**Meta Business Suite:** для IG/FB.
**TikTok Analytics:** для TT.
**GA4:** для трафіку на сайті.
**Looker Studio:** комбінований дашборд для менеджменту.

## 6. KPI дерево

**Кінцевий KPI:** Sales growth +30% YoY.
→ **Awareness:** +25% reach IG, +50% підписників.
→ **Consideration:** +20% переходів на сайт, +30% директів.
→ **Conversion:** нові партнери +5/квартал, конверсія IG→sale +1%.
→ **Loyalty:** +10% повторних покупців, NPS ≥ 8.

## 7. Не міряємо

— Рекламний ROAS окремо від organic.
— Схильність клієнтів (NPS, soft metric).
— Рівень задоволеності партнерів.
— Природні виклики бренду медіа.
— SOV (share of voice) vs конкурентів.

## 8. Автоматизація

— Supermetrics / Funnel.io — вивантаження даних.
— Looker Studio — візуалізація.
— Notion — лог кампаній, планування.
— Slack alerts — авто-сповіщення про критичні падіння KPI.
