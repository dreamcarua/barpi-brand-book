📐 Правила touchpoint hierarchy📐 Touchpoint Hierarchy Rules

  1. Кожен touchpoint = ОДИН primary message. Не намагатись передати все — обрати головне для цього контексту. Each touchpoint = ONE primary message. Don't try to say everything — pick the main one for context.
  2. Top-funnel (awareness) — емоційні меседжі, мінімум фактів. Top-funnel (awareness) — emotional messages, minimum facts.
  3. Mid-funnel (consideration) — деталі продукту, склад, EAN. Mid-funnel (consideration) — product details, composition, EAN.
  4. Bottom-funnel (purchase) — простота: ціна, наявність, doc. Bottom-funnel (purchase) — simplicity: price, availability, doc.
  5. Post-purchase (loyalty) — community: UGC, амбасадори, новинки. Post-purchase (loyalty) — community: UGC, ambassadors, new SKUs.
