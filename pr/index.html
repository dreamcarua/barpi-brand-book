🎯 3 рівні криз3 Crisis Levels

L1 · LOW

Поодинокі скаргиIsolated complaints

Приклади: «не сподобався запах», «мій собака не їсть», «трохи дрібні шматочки». Це особисті переваги — не дефекти. Examples: "didn't like the smell", "my dog won't eat", "pieces too small". Personal preferences — not defects.

Дія:Action: SMM відповідає за скриптом протягом 2 годин. Якщо клієнт незадоволений — пропонуємо обміняти/повернути. SMM replies per script within 2 hours. If unhappy — offer exchange/refund.

L2 · MEDIUM

Кілька скарг на одну партіюMultiple complaints on one batch

Приклади: «продукт зіпсувався раніше терміну», «плісняв на 3 пачках з тієї ж партії», «алергічна реакція». Це системний сигнал. Examples: "spoiled before expiry", "mold on 3 packs same batch", "allergic reaction". Systemic signal.

Дія:Action: Олександр (COO) перевіряє партію за номером, вантажне відвантаження. Дзвінок клієнтам, заміна, документація. Шукаємо ще скарги на цю партію проактивно. Oleksandr (COO) checks batch, shipment records. Call customers, replace, document. Proactively look for more complaints on this batch.

L3 · HIGH

Recall / медіа-резонанс / отруєнняRecall / media attention / poisoning

Приклади: офіційне розслідування Держпродспоживслужби, журналіст звертається, віральний пост у соцмережах, отруєння домашнього улюбленця. Examples: official investigation by State Service, journalist inquiry, viral social media post, pet poisoning.

Дія:Action: Кризовий комітет: Vadym + Pylyp + Oleksandr + юрист. Публічна заява протягом 1 години. Відкликання партії — оголошення на сайті + Instagram + email + у мережах. SMM призупиняє promo-постинг. Crisis committee: Vadym + Pylyp + Oleksandr + lawyer. Public statement within 1 hour. Batch recall — announcement on site + Instagram + email + retail chains. SMM pauses promo posting.
