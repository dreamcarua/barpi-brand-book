🚨 PR & кризові комунікаціїPR & Crisis Communications

Як Barpi реагує на скарги, кризи і запити media. Алгоритми, шаблони, скрипти, контакти. How Barpi responds to complaints, crises, and media inquiries. Algorithms, templates, scripts, contacts.

Спокійно. Чесно. По суті.

Barpi не ігнорує проблему. Не сперечається. Не обіцяє того, що не може підтвердити.
Barpi збирає факти, перевіряє, повертається з рішенням.
Calmly. Honestly. To the point.

Barpi doesn't ignore. Doesn't argue. Doesn't promise what it can't confirm.
Barpi gathers facts, verifies, returns with a solution.

📋 Алгоритм відповіді (5 кроків)Response Algorithm (5 steps)

  1. Почути → подякуватиListen → thank
  2. Зібрати фактиGather facts — batch number, photos, description, date, location.
  3. Передати відповідальномуPass to responsible — L1 SMM, L2 COO, L3 Founders.
  4. Повернутись з рішеннямReturn with solution — SLA: L1 ≤ 2h, L2 ≤ 24h, L3 ≤ 1h public.
  5. Зафіксувати кейсLog the case — CRM/Customer 360.

🎯 3 рівні криз3 Crisis Levels

L1 · LOW

Поодинокі скаргиIsolated complaints

Action: SMM відповідає протягом 2 годин. Обмін/повернення.SMM replies within 2h. Exchange/refund offered.

L2 · MEDIUM

Кілька скарг на партіюMultiple complaints on batch

Action: COO перевіряє партію, дзвінок, заміна.COO checks batch, calls, replaces.

L3 · HIGH

Recall / media / отруєнняRecall / media / poisoning

Action: Кризовий комітет: Vadym + Pylyp + COO + юрист. Публічна заява за 1год.Crisis committee. Public statement within 1h.
